# 📄 AI Resume Analyzer

An AI-powered **Resume Analyzer** built using **Java, Spring Boot, Google Gemini API, WebClient, Thymeleaf, HTML, CSS, JavaScript, and MySQL**.

The application analyzes a user's resume and provides AI-generated insights, suggestions, and feedback to help improve the resume.

---

## 📌 Project Overview

**AI Resume Analyzer** is a web-based application designed to help job seekers analyze and improve their resumes using Artificial Intelligence.

The application allows users to provide their resume information and uses the **Google Gemini API** to analyze the resume and generate useful feedback.

The backend is developed using **Spring Boot**, while **Spring WebClient** is used for communication with the Google Gemini API. The frontend is developed using **HTML, CSS, JavaScript, and Thymeleaf**.

The project demonstrates practical implementation of:

- Java
- Spring Boot
- REST APIs
- Spring WebClient
- Google Gemini API
- MySQL
- JPA/Hibernate
- Thymeleaf
- HTML/CSS/JavaScript
- Maven
- Git/GitHub

---

## 🎯 Objective

The main objective of this project is to create an AI-powered resume analysis system that helps users understand the quality of their resume and identify areas for improvement.

The application provides AI-generated feedback about:

- Resume strengths
- Resume weaknesses
- Technical skills
- Missing skills
- Resume improvement suggestions
- Project descriptions
- Professional summary
- Job-role relevance
- Overall resume quality

---

# 🚀 Features

## 📤 Resume Upload

Users can upload or provide their resume through the web interface.

The application processes the resume information and sends the relevant content for AI analysis.

---

## 🤖 AI-Powered Resume Analysis

The application integrates the **Google Gemini API** to analyze resume content.

The Spring Boot backend communicates with Gemini using **Spring WebClient**.

The AI analyzes the resume and generates structured feedback.

---

## 📊 Resume Evaluation

The system evaluates different sections of the resume and provides useful feedback.

The analysis can include:

- Professional Summary
- Education
- Technical Skills
- Projects
- Work Experience
- Achievements
- Certifications
- Overall Resume Quality

---

## 💡 Resume Improvement Suggestions

The AI provides suggestions to improve the resume.

For example:

- Improve the professional summary
- Use stronger action words
- Add measurable achievements
- Improve project descriptions
- Add relevant technical skills
- Remove unnecessary information
- Improve resume formatting
- Make descriptions more concise
